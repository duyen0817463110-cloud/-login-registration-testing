1. Project Overview
This project focuses on end-to-end testing of the Login and Registration modules of a web application. The objective is to verify that the system behaves as expected based on the provided Software Requirement Specifications (SRS).
The project combines manual testing and test automation using Python and Selenium WebDriver.

2. Project Objectives
Verify the functional correctness of Login and Registration modules.
Validate input fields, data constraints, and error messages.
Identify defects through positive and negative test scenarios.
Apply black-box testing techniques to improve test coverage.
Automate selected test cases to support repetitive test execution.

4. Testing Scope
Login Module
Valid and invalid username/password combinations.
Empty input validation.
Input length validation.
Password masking.
Session persistence using cookies.
Login submission using the Enter key.
Registration Module
Required field validation.
Input length and format validation.
Email and phone number validation.
Username uniqueness and password constraints.
Password confirmation validation.
Password masking.

5. Testing Techniques

Functional Testing

7. Test Automation Workflow
Read test data from Excel files using Pandas.
Initialize Chrome WebDriver.
Navigate to the local web application.
Execute test cases using Selenium WebDriver.
Capture actual system responses.
Compare actual results with expected results.
Export test execution results to Excel files.
